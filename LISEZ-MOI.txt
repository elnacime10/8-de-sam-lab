LE 8 DE SAM — version 2.1 (le fil et le rythme)

CE QUE CONTIENT CETTE ARCHIVE
  Tout le jeu. Elle remplace entièrement ce qui est sur le dépôt.

DÉPÔT
  1. Extraire l'archive (clic droit > Extraire tout).
  2. Ouvrir le dossier obtenu, sélectionner TOUT son contenu (Ctrl+A).
  3. GitHub : Add file > Upload files, glisser la sélection À LA SOURIS.
  4. Vérifier en bas : js/reseau.js, data/personnages.js, css/style.css.
  5. Commit changes. Puis attendre la coche verte dans l'onglet Actions.

IMPORTANT
  Le format des messages entre joueurs a changé : TOUT LE MONDE doit
  être en 2.0 pour jouer ensemble. Un joueur resté en ancienne version
  est désormais refusé avec un message clair, au lieu d'entrer dans une
  partie où il ne comprend que la moitié de ce qui se passe.

  Version affichée en bas de l accueil : 2.1
